# 离散音量曲线设计

## 产品语义

曲线把“按多少次”与“用多少个点塑形”拆为两个参数，再在整数按键位置生成 Android 媒体音量目标。

设当前可编辑基准范围为 `minIndex..maxIndex`，跨度 `S = maxIndex - minIndex`：

- `K` 是从最小到最大需要的短按次数，实际按键状态位于整数位置 `n = 0…K`，渲染坐标为 `xₙ = n / K`；
- `P` 是搭建折线的控制点总数，包含两个固定端点；每个控制点保存整数按键位置 `qⱼ`，满足 `0 = q₀ < … < qₚ₋₁ = K`，控制点之间不要求均匀；
- 控制点纵轴保存整数 offset `cⱼ`，满足 `c₀ = 0`、`cₚ₋₁ = S`，中间值严格递增；
- 实际第 `n` 次按键先在 `xₙ` 对控制折线 `C(x)` 做线性采样，再用全局最小平方整数投影得到严格递增的目标表 `I[n]`；控制点的归一化 X 只由 `qⱼ / K` 派生，不作为持久化真值；
- `ΔI[n] = I[n] - I[n-1]` 表示这一按跨越多少个系统 index，也是判断低音量区域是否足够细的主要指标。

严格整数约束基于保存配置的基准跨度，因此模型满足 `1 ≤ K ≤ S_basis`、`2 ≤ P ≤ K+1`；正式界面的控制点数量上限再限制为 `min(16, K+1, S_basis+1)`。`P < K+1` 时多个按键位置共享同一折线段；`P = K+1` 时每个整数按键位置都可成为控制点。如果当前路由跨度 `S_route` 更小，运行时采用 `K_effective = min(K, S_route)` 并重新投影实际按键目标；保存的整数控制曲线不会被较小路由覆盖。

当系统或耳机把音量外部改到两个配置点之间时，音量加选择第一个严格大于当前 index 的点，音量减选择最后一个严格小于当前 index 的点。这样不会先跳回旧状态，也不会依赖浮点反解的舍入方向。

## 编辑交互

正式版只保留一个主界面，不使用 Tab，也不常驻诊断、历史或独立的精确值面板：

1. “控制点数量”位于图表上方，只读显示当前 P，并使用 `−` / `+` 对当前选择执行一次删除或插入；“按键次数”位于 x 轴下方，仍可直接输入整数或使用 `−` / `+` 单步调整。控制点数量范围为 `2…min(16, K+1)`，按键次数下限随 P 变化为 `P-1`；K 输入在完成编辑或失去焦点时提交并约束到有效范围。
2. 控制点和相邻控制点组成的线段是互斥的两种选择。点按控制点进入点选择，点按折线进入线段选择；主画布不再绘制每个按键对应的采样小点。选中点使用克制的光晕，选中线段用稍宽的强调线表示，不额外增加装饰点。
3. 选中的中间控制点可同时横向和纵向拖动。x 无条件吸附到最近的整数按键位置，y 无条件吸附到整数 index；选中点始终用两条虚线分别延伸到 x/y 轴。控制点不能越过相邻点，两端固定为 `(0, 0)` 与 `(K, S)`，也不能被删除。
4. 当前系统音量用绿色水平线、与折线的交点和“当前 n”标签共同标记；水平线对应 y 轴的真实 index，交点给出它在按键轴上的反解位置。
5. 图表优先占用主界面空间：绘图区压缩无效留白，画布高度随窗口高度自适应并限制在适合手机操作的范围；外层卡片和页面水平边距保持较小。图表下方只有固定长按步进间隔设置，范围 `60…500 ms`、步长 `20 ms`。设备与授权状态收纳在“设备”折叠区；没有 Undo/Redo、精确值编辑、说明菜单或诊断主页面。

辅助能力包括：

- 拖动过程中只更新界面草稿，正常抬手时一次性提交；路由或外部配置变化导致手势取消时回滚到最新来源，不留下未持久化草稿；
- 画布为点选择和线段选择提供不同的 TalkBack 状态描述与操作；跨基准路由上的纵向操作按“下一个可表示档位”移动，控制点数量、按键次数、长按间隔和设备开关使用标准 Compose 控件语义；
- y 轴的常规刻度同时显示静音、低、中、高音量图标；选中点的 X 值与 x 轴刻度共用同一基线，距离过近时由选中值替代普通刻度。

## 点数变化与跨设备投影

修改 `K` 时，旧控制点按归一化位置投影到新的 `0…K` 整数网格，并保持端点、顺序和至少一个按键位的间隔；纵轴值不变。运行时在新的 `n/K` 位置采样折线，再求满足固定端点和严格递增约束的整数目标序列。

修改 `P` 时保持 `K` 不变，但不再由算法自动挑选增删位置。选择一条同时具有空余整数 X 和 Y 坐标的线段后按 `+`，新点插入该段的整数中点：X 跨度为奇数时采用较小的中间整数，Y 取原折线上最近且能保持严格递增的整数；现有控制点不会为插入让位或漂移。新增后选择切换到新点。选择一个内部控制点后按 `−`，只删除该点，随后选择切换到左右邻点合并成的新线段；端点不可删除。没有空余整数坐标、达到 P 上限或当前选择类型不匹配时，相应按钮保持禁用。

运行时仍只在均匀的 `n/K` 位置采样，再用确定性的最小平方动态规划得到严格递增的整数目标表，复杂度为 `O(K × S)`。内部的批量重采样能力仅用于旧设置迁移或显式 rebase，不作为正式界面的 P 调整交互。

切换到不同厂商或不同音频路由时使用同一过程把作者折线缩放到实际跨度。设置始终保存完整基准曲线；较小路由只改变运行时 `Δindex` 结果，编辑按键次数、控制点数量或控制点都不会顺带固化临时降采样。画布纵轴显示当前路由的实际 audio index，控制点编辑再确定性换算回完整基准 offset。

`rebase()` 仅用于显式建立新的整数编辑基准。它先尝试保留 P 个控制点和曲线形状；如果二次整数量化会改变当前路由已经绑定出的 `K+1` 个目标，则回退为每个实际目标一个控制点，优先保证重建前后的按键行为完全一致。

## 开源交互调研

没有找到一个 Android/Compose 开源控件同时提供“非均匀整数控制点、均匀按键采样、双轴吸附、整数纵坐标、严格单调和按键次数语义”。直接引入通用图表库仍需自行实现命中测试、手势事务和约束求解，所以本项目使用 Compose `Canvas` 与标准 Material 控件组合，不增加图表依赖。

可复用的是以下成熟产品模式，而不是直接复制代码：

| 项目 | 可借鉴交互 | 采用方式与许可证边界 |
|---|---|---|
| [Godot CurveEdit](https://github.com/godotengine/godot/blob/master/editor/plugins/curve_editor_plugin.cpp) | 点拖动、吸附、轴锁定、预设、按一次手势记录撤销 | MIT；借鉴手势事务和约束反馈 |
| [AOSP Camera2 ImageCurves](https://android.googlesource.com/platform/packages/apps/Camera2/+/394baebc5579fa9c3f7e09bfbcac7ef666f6c002/src/com/android/gallery3d/filtershow/imageshow/ImageCurves.java) | 移动端触摸命中、拖点与相邻点边界 | Apache-2.0；借鉴移动端直接操控方式 |
| [Audacity Envelope Tool](https://manual.audacityteam.org/man/envelope_tool.html) | 包络线点编辑、视觉反馈 | 文档用于交互参考；GPL 实现不进入本项目 |
| [Ardour Automation](https://manual.ardour.org/mixing/automation/controlling-a-track-with-automation/) | 画笔式自动化、范围选择与精调 | 文档用于交互参考；GPL 实现不进入本项目 |
| [Vico](https://github.com/patrykandpatrick/vico) / [MPAndroidChart](https://github.com/PhilJay/MPAndroidChart) | Android 图表绘制、缩放和标记 | 都擅长展示，但没有本项目需要的受约束点编辑；不引入 |
| [32steps](https://github.com/nulldio/32steps) | 离散步数与响度细分的 Android 实验 | 其额外精度依赖播放 session 上的 DSP 增益，不等同于全局 `STREAM_MUSIC` index 曲线；仅作边界对照 |

`32steps` 一类方案可以通过 [`DynamicsProcessing`](https://developer.android.com/reference/android/media/audiofx/DynamicsProcessing) 在自己掌控的 `AudioTrack`/`MediaPlayer` session 内增加 index 之间的增益级，但本应用控制的是其他应用共同使用的全局媒体音量。把 session DSP 当作全局保证会受到播放器、音效链和厂商实现限制，因此当前版本明确把纵轴保持为系统 audio index。

## 应用图标

启动图标沿用 Android adaptive icon，并使用与主界面一致的克制配色。背景为深蓝 `#33466F`；前景只保留一条上升的分段映射曲线、普通控制点和一个同色荧光光晕强调的选中控制点，不使用耳机品牌形象、坐标轴或复杂声波。Android 13 及以上的 themed icon 使用相同轮廓的单色资源，节点大小和光晕仍能表达“选中控制点”。

## 可验证不变量

- v4 持久化同时包含 `K` 以及每个控制点的整数 `(pressPosition, offset)`，P 由控制点数量得到；v1–v3 载入时一次性投影到整数网格；
- 控制点横坐标是 `0…K` 内严格递增的整数，归一化 X 只用于绘制与插值；
- 控制点和实际按键目标都固定端点、使用整数 index 且严格递增；
- 修改 `K` 不改变 P 或纵轴值，并把 X 重投影到新整数网格；通过选段插入或选点删除修改 P 时不改变 K；
- 点与线段选择互斥；新增只发生在选中线段，删除只作用于选中的内部点，端点不可删除；
- x/y 拖动始终硬吸附到整数坐标；
- 当前音量水平标记只反映系统读数，不修改作者曲线；
- 长按在固定延迟后严格按已配置的毫秒间隔前进相邻映射状态；
- 同一路由上的短按只移动到相邻配置状态，外部 index 则按方向选择严格相邻目标；
- 点数变化和跨范围投影结果确定、可重复；
- 固定音量路由没有可用步骤，控制器保持 fail-open；
- Android index 写入回读成功只证明系统接受该 index，不保证蓝牙耳机固件产生可听差异。
