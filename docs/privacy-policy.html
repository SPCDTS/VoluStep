概述

VoluStep 是一款在 Android 设备本地运行的实体音量键映射工具。应用不包含联网权限、广告 SDK、分析 SDK 或账号系统，不会把按键、音量、设备或配置数据上传到开发者服务器，也不会出售或与第三方共享这些数据。

应用处理的信息

  • 实体按键事件：Android 可能向无障碍服务投递其他实体按键事件。应用会先检查键码，并立即忽略、放行非音量键；对于音量加减键，会在内存中临时使用键码、按下/释放状态、重复次数、按下时间、事件时间和输入设备标识，用于区分一次按键手势、判断短按或长按，以及避免重复处理。事件数据不会写入持久化设置。
  • 媒体音量与输出路由：应用使用 Android 公开的音频 API 读取和设置媒体音量整数 index，并在本机查询当前输出路由、音量范围和系统提供的名义 dB 信息。应用无法读取耳机内部真实增益或声压级。
  • 本地配置：映射曲线、按键参数和显著披露同意状态保存在应用私有存储中。该设置文件被排除在 Android 云备份和设备到设备迁移之外。
  • 本机设备信息：主界面仅在本机显示厂商、输出路由名称和音量范围。开发者主动运行的本地诊断脚本可能另行记录设备型号和 Android 版本；应用不会自动上传这些信息。

无障碍服务

为了在 Android 和设备厂商实际投递按键事件时，于其他应用、桌面或锁屏场景应用用户设置的音量映射，VoluStep 需要用户在系统设置中主动启用无障碍服务。该服务：

  • 检查系统投递事件的键码并立即放行非音量键，只进一步处理手机实体音量加、音量减按键；
  • 不读取窗口内容、屏幕文字、触摸、截图、密码、账号或其他应用内容；
  • 不执行自动点击，不代表用户操作其他应用；
  • 仅在用户明确同意披露、完成系统授权并开启 VoluStep 后参与映射。

用户可以关闭 VoluStep 总开关或在 Android 系统设置中停用无障碍服务，以恢复系统默认按键行为。

前台服务与系统权限

VoluStep 使用 MODIFY_AUDIO_SETTINGS 读取和设置 Android 媒体音量，并使用用户主动启动的 specialUse 前台服务维持即时按键映射。前台服务只在本机运行，不会产生网络传输。Android 仍可能在系统“运行中的应用”等位置展示并允许停止该服务。

数据保留与删除

本地配置会保留到用户修改设置、清除应用数据或卸载 VoluStep。清除应用数据或卸载会由 Android 删除应用私有配置。由于 VoluStep 没有账号、开发者服务器或服务器端用户数据，因此不存在服务器端账号删除或数据删除申请流程。

第三方与设备边界

Android、手机厂商系统和蓝牙设备可能自行处理按键、输出路由、绝对音量、安全音量或电池策略。耳机自身按键或触控可能不会经过 VoluStep。相关系统和设备由各自提供方负责，其数据处理受相应提供方政策约束。

儿童隐私

VoluStep 不要求用户创建账号，也不会有意收集儿童或其他用户的个人信息。

政策变更

如果应用能力或数据处理方式发生变化，本页会在新版本发布前更新日期与内容。若变化需要新的系统权限、显著披露或同意，应用会按适用规则重新向用户说明。

Overview

VoluStep is a physical volume-button mapper that runs locally on an Android device. The app has no Internet permission, advertising SDK, analytics SDK, or account system. It does not upload button, volume, device, or configuration data to a developer server, and it does not sell or share that data with third parties.

Information processed by the app

  • Physical key events: Android may deliver other physical-key events to the Accessibility service. The app first checks the key code and immediately ignores and passes through non-volume keys. For volume-up and volume-down, it temporarily uses the key code, press/release state, repeat count, down time, event time, and input-device identifier in memory to identify one button gesture, distinguish a short press from a hold, and prevent duplicate handling. Event data is not written to persistent settings.
  • Media volume and output route: The app uses public Android audio APIs to read and set the integer media-volume index and to query the current output route, volume range, and nominal dB information supplied by the system. It cannot read an earphone's internal gain or real sound-pressure level.
  • Local configuration: The mapping curve, button parameters, and prominent-disclosure consent state are stored in app-private storage. This settings file is excluded from Android cloud backup and device-to-device transfer.
  • On-device information: The main screen displays the manufacturer, output-route name, and volume range only on the device. Local diagnostics started manually by a developer may additionally record the device model and Android version. The app does not upload this information automatically.

Accessibility service

VoluStep asks the user to enable an Accessibility service in Android settings so it can apply the user's volume mapping in other apps, on the Home screen, or on the lock screen when Android and the device manufacturer actually deliver the relevant button events. The service:

  • checks the key code of delivered events, immediately passes through non-volume keys, and further processes only the phone's physical volume-up and volume-down buttons;
  • does not read window content, on-screen text, touch input, screenshots, passwords, accounts, or content from other apps;
  • does not perform automated clicks or act on the user's behalf in other apps; and
  • participates in mapping only after the user accepts the prominent disclosure, grants access in system settings, and turns on VoluStep.

The user can turn off VoluStep or disable its Accessibility service in Android settings to restore the system's default button behavior.

Foreground service and system permission

VoluStep uses MODIFY_AUDIO_SETTINGS to read and set Android media volume. A user-started specialUse foreground service keeps button mapping immediate. The foreground service runs only on the device and does not cause network transmission. Android may still show the service in system surfaces such as “Active apps” and allow the user to stop it.

Retention and deletion

Local configuration remains until the user changes it, clears the app's data, or uninstalls VoluStep. Android removes app-private configuration when app data is cleared or the app is uninstalled. VoluStep has no account, developer server, or server-side user data, so there is no server-side account or data-deletion request process.

Third-party and device boundaries

Android, the phone manufacturer's software, and Bluetooth devices may independently handle buttons, audio routes, absolute volume, safe-volume limits, or battery policies. Buttons or touch controls on an earphone may not pass through VoluStep. Those systems and devices are provided by their respective parties and are governed by their own policies.

Children's privacy

VoluStep does not require an account and does not knowingly collect personal information from children or other users.

Changes to this policy

If the app's capabilities or data practices change, this page will be updated before the relevant release. If a change requires a new system permission, prominent disclosure, or consent, the app will explain it again as required.
