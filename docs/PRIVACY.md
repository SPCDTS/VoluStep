# 隐私说明

更新日期：2026-09-08

VoluStep 在设备本地处理实体音量键和媒体音量设置，不包含联网权限、广告 SDK、分析 SDK 或账号系统，不上传、出售或与第三方共享数据。应用内菜单也可查看隐私说明。

## 数据与权限用途

- **无障碍服务：** 系统可能投递其他实体按键事件，应用检查键码后立即放行非音量键。音量键的键码、按下与释放状态、重复次数、事件时间和输入设备标识仅在内存中用于识别手势、判断长按和清理未完成手势，不持久化。服务禁止读取窗口内容，不读取其他应用文字、触摸内容或截图。
- **音量权限：** `MODIFY_AUDIO_SETTINGS` 用于公开媒体音量接口，应用读取当前输出路由、音量范围和系统名义 dB 表，并设置整数媒体音量。固定音量按钮不需要无障碍服务。
- **前台服务：** 用于持续处理用户启用的全局按键映射。应用向系统提交前台服务所需通知，但不申请通知权限；Android 13 及以上的普通通知抽屉不显示该通知，系统前台服务管理入口仍可展示和停止服务。
- **本地设置：** 曲线、固定音量、按键参数和披露同意状态保存在应用私有 DataStore 中。该设置文件排除在 Android 云备份和设备迁移之外，换机后需要重新同意披露并配置设置；原设备直接升级保留本地设置。
- **设备信息：** 设备区域在本机显示厂商、输出路由和音量范围。开发者手动运行的诊断脚本另行保存本地日志，不会自动上传。

## 用户控制

启用无障碍前，应用会展示独立权限说明并要求主动同意。用户可以通过主开关停止映射，也可以在系统设置中关闭无障碍、清除应用数据或卸载应用。应用不在开机后自动启动控制器。

## 能力边界

应用不绕过 Android 的安全音量提示、勿扰模式或厂商权限裁决，也无法读取耳机内部的真实声压级。设备和蓝牙限制见 [兼容性说明](OEM_COMPATIBILITY.md)。
