# 隐私说明

更新日期：2026-08-24

音量映射器只在设备本地处理实体音量键和媒体音量设置，不包含联网权限、广告 SDK、分析 SDK 或账号系统，也不会上传、出售或与第三方共享数据。

## 使用的数据与权限

- 无障碍服务只接收音量上、音量下的 `KeyEvent`，并临时使用键码、`downTime`、event time 和输入设备标识组成手势 token、判断短按/长按与丢失的 UP；这些事件数据不写入 DataStore。服务明确禁止读取窗口内容，不读取文字、触摸、截图或其他应用内容。
- `MODIFY_AUDIO_SETTINGS` 仅用于读取和设置公开的 `STREAM_MUSIC` 整数音量档位，并查询当前输出路由的系统名义 dB 表。
- 前台服务与通知仅用于让全局按键映射持续运行，并提供随时可见的停止入口。
- 映射曲线、按键参数和披露同意状态保存在应用私有 DataStore 中。由于这些内容目前共用同一个文件，首版会把整个文件排除在 Android 云备份和设备到设备迁移之外，避免在新设备恢复披露同意状态后跳过显著披露。因此，用户换机或从云备份恢复后需要重新同意披露并配置全部设置；原设备上的应用直接升级仍会保留本地设置。应用自身不会把这些内容上传到开发者服务器。
- 诊断页显示的厂商、型号、系统版本、路由名称和音量范围只在本机展示。诊断采集脚本由开发者主动运行，输出保存在本地且不会自动上传。

## 用户控制

用户可以从应用或持续通知立即停止映射，也可以在系统设置中关闭无障碍服务、通知权限或清除应用数据。应用不在开机后自动启动控制器。

## 能力边界

应用不会绕过 Android 的安全音量提示、勿扰模式或厂商权限裁决。蓝牙耳机可能自行处理绝对音量；应用无法读取或控制耳机内部的真实声压级。

正式发布前，发布者应在商店页面提供可公开访问的本说明链接，并补充有效的联系邮箱和发布主体信息。
